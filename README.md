# Hall Escape – Das Stadträtsel-Abenteuer

Offizielle Website für **Hall Escape** in Schwäbisch Hall.

- **Website:** Stadträtsel & Outdoor Escape Game
- **Treffpunkt:** Friedrichstraße 19, 74523 Schwäbisch Hall
- **Hosting:** Netlify (mit Netlify Forms & WhatsApp Support)

## Lokale Vorschau
Einfach `index.html` in einem beliebigen Browser öffnen oder einen lokalen Webserver starten:
```bash
npx serve .
```

## Deployment auf Netlify
1. Dieses Repository in Netlify verknüpfen („Import from Git“).
2. Build-Kommando leer lassen (statisches HTML).
3. Publish-Verzeichnis: `.` (bzw. leer lassen).
